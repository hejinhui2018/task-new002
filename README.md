# 展位排布工作台

面向会展运营团队的展位排布工具：在搭建前发现**展位重叠、通道过窄、出口被堵**等问题。
纯前端实现（React + TypeScript + Vite），数据保存在浏览器 `localStorage`，无需后端。

## 运行方式

```bash
npm install        # 安装依赖
npm run dev        # 启动开发服务器（默认 http://localhost:5173）
npm test           # 运行单元测试（vitest）
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 预览生产构建
```

## 功能

- **展厅画布**：20m × 14m 展厅平面图，0.5m 细网格 + 1m 粗网格 + 米制刻度，北墙两个固定出口（A/B），门前标出 1.5m 净空区。
- **展位编辑**：添加、拖拽移动、四角手柄缩放、90° 旋转（按钮或 `R` 键）、删除（`Delete` 键）。所有位置和尺寸吸附到 0.5m 网格。
- **画布导航**：滚轮以鼠标为锚点缩放，拖拽空白处平移，右上角按钮放大/缩小/适应展厅。缩放后拖拽落点与尺寸换算仍然准确（屏幕坐标先换算回世界坐标再吸附）。
- **撤销 / 重做 / 重置**：`Ctrl/⌘+Z`、`Ctrl/⌘+Shift+Z`（或 `Ctrl+Y`），可一键恢复内置示例方案或清空；重置本身也可撤销。
- **实时校验**（拖拽过程中即刷新）：
  | 规则 | 级别 |
  | --- | --- |
  | 展位超出展厅边界 | 错误 |
  | 展位互相重叠 | 错误 |
  | 展位间通道 < 1.5m | 提醒 |
  | 占用出口门前 1.5m 净空区 | 错误 |
  | 接待点无法到达任一出口（疏散路径被堵） | 错误 |
- **疏散路径**：从每个展位正面（粗绿边）的接待点（绿点）出发，在 0.5m 网格上 BFS 寻找通往最近出口的可走路径，选中展位即以虚线箭头显示；找不到时在接待点标 ✕。
- **告警定位**：右侧面板按类型分组列出所有告警，点击告警后相关展位在图上以蓝色虚线框 + 序号徽标高亮，面板显示原因和涉及展位；图上的告警展位带 ⚠ 三角徽标和斜纹填充，不依赖颜色也能识别。
- **内置示例**：首次打开（或点「重置为示例方案」）载入一个“出口被堵”的方案——A1/B1/A2 连成隔墙把 C1 困在南侧。把 B1 拖开，C1 的告警和疏散路径会立即更新。

## 实现要点

```
src/
  lib/
    constants.ts     展厅尺寸、网格、通道宽度、出口定义
    geometry.ts      网格吸附、屏幕↔世界坐标换算、缩放锚点、旋转/有效占位、矩形关系
    pathfinding.ts   0.5m 网格 BFS 疏散路径搜索
    validation.ts    全量校验（越界/重叠/通道/出口净空/可达性）
    history.ts       撤销/重做历史栈
    samples.ts       内置「出口被堵」示例方案
    persistence.ts   localStorage 读写
  components/
    FloorPlan.tsx    SVG 画布：网格、出口、展位、路径、告警标注、拖拽/缩放/平移交互
    Toolbar.tsx      工具栏（添加/旋转/删除/撤销/重做/重置 + 告警统计）
    WarningsPanel.tsx 告警分组列表
    Inspector.tsx    展位属性编辑
  lib/__tests__/     单元测试
```

- **坐标系**：世界坐标以米为单位，SVG 通过 `translate(pan) scale(zoom)` 变换；指针事件统一经 `screenToWorld` 换算后再做 0.5m 吸附，因此任意缩放级别下拖拽和缩放都精确落格。
- **旋转**：只支持 90° 倍数，存储未旋转的 `x/y/w/h + rotation`，实际占位由 `effectiveRect` 推导（绕中心互换宽高），保证占位始终轴对齐、便于碰撞计算。
- **疏散路径**：展厅离散为 40×28 的 0.5m 网格，展位占据的格子不可通行，从接待点所在格 BFS 到任一出口门内格；接待点被压住时向外搜索最近空格。

## 测试

`npm test` 运行 vitest，覆盖：

- `geometry.test.ts` — 网格吸附、屏幕↔世界坐标互逆、缩放锚点不变、旋转/接待点/有效占位、矩形重叠与间距、拖角缩放换算
- `validation.test.ts` — 越界、重叠、1.5m 通道边界值、出口净空区、示例方案的「出口被堵」告警
- `pathfinding.test.ts` — 可达性、示例中 C1 被堵、移开 B1 后恢复、路径不穿展位不出界
- `history.test.ts` — 提交/撤销/重做、future 清空、空栈安全、重置可撤销、历史上限
